    override refuses the projection fields (commercial_projection_json,
    net_revenue_projection, fx_*) for anyone without that token - sudo, a raw
    context flag, a guessed token, an import context or a direct write. Field-level
    security on net_revenue_projection and the other COST_GROUP fields is untouched;
    no group is granted to Sales users; Taleghani's permissions are unchanged.
